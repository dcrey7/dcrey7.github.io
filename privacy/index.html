Privacy policy for youtube-dcrey7-stats

Last updated: 22 October 2026

youtube-dcrey7-stats is a private tool. Only the owner of the dcrey7 YouTube channel uses it.

Google scopes it asks for

  • https://www.googleapis.com/auth/yt-analytics.readonly: read the channel's own YouTube Analytics reports.

That is the only scope. It is read-only: the tool cannot upload, edit or delete anything.

What it does with the data

It reads the channel's own YouTube Analytics numbers. The numbers stay on the owner's computer. The tool does not share, sell or send them to anyone, does not use them for ads, and does not use them to train AI models.

The tool collects no data about other people.

Limited Use

youtube-dcrey7-stats's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Open your Google Account, then Security, then Third-party apps, and remove the app, or go straight to myaccount.google.com/permissions. The owner can also delete the stored token and data from the computer at any time.
